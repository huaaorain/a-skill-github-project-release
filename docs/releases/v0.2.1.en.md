## Summary

`0.2.1` adds a pre-upload security check and establishes a license-selection workflow. It scans source files, untracked files, unpushed Git history, and Release ZIPs for common credentials, and requires an explicit user choice when a project has no license. This skill itself now uses PolyForm Noncommercial License 1.0.0.

## Highlights

- Added `security-check` for tracked, staged, non-ignored untracked, and unpushed Git-history content, plus ZIP release artifacts.
- Detects common credential filenames, private keys, GitHub/cloud/AI/payment tokens, and literal password, API-key, or token assignments.
- Reports only the location and finding category, never the matched secret value.
- `preflight` now runs the full security audit and blocks publication on real credential findings.
- Before a first public upload, presents MIT, Apache-2.0, BSD-3-Clause, MPL-2.0, GPL-3.0-only, AGPL-3.0-only, and source-available alternatives for an explicit user choice.
- Clearly distinguishes OSI open-source licenses from source-available licenses that prohibit commercial use or resale.
- This skill is licensed under PolyForm Noncommercial License 1.0.0 with a Required Notice attribution.

## Fixes

- Expanded secret checks from a few tracked files to source, release archives, and unpushed history.
- Prevents `.env`, private keys, token files, and common hard-coded credentials from entering Git or Release assets.
- Prevents public publication without a license decision when no license exists.

## Compatibility and upgrade

- Upgrading from `0.2.0` requires no migration of `version_surfaces` or release manifests.
- Existing projects can run `security-check --root .` for a source-only pass, then `security-check --spec .github/release-spec.json` to include release artifacts.
- `.env.example`, `.env.sample`, and `.env.template` may contain placeholders but not real credentials.
- This project is not OSI open source. Commercial use requires a separate license and must not be described as open source.

## Platforms and limitations

- Windows, macOS, and Linux.
- GitHub.com and the GitHub REST API.
- Automated scanning cannot prove a repository is secret-free or detect sensitive information visible in a PNG/JPEG or internal encrypted application resources.
