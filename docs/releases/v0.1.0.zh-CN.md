## 版本摘要

`0.1.0` 是 A Skill: Github Project Release 的首个公开发布版本，提供从项目检查、GitHub 建库、源码推送、Draft Release、附件上传到 README 与多语言版本目录维护的完整工作流。

## 主要更新

- 首次公开发布默认使用 `0.1.0`。
- 默认采用 `release-only`：源码进入 Git，可执行程序与分发文件只上传到 Release。
- 支持首次建库与已有仓库的新版本发布。
- 为每个附件生成用途、类型、大小和 SHA-256 清单。
- 支持 Draft Release、附件续传和发布前一致性校验。
- 支持简体中文、繁体中文和英文 README，并同步更新版本目录。

## 问题修复

- Draft Release 通过已认证的 Release 列表发现。
- Draft 附件通过 Release Asset API 读取，避免临时链接失效。
- 默认初始版本由发布配置约束，并包含离线回归测试。

## 兼容性与升级

- 运行环境需要 Python 3.10 或更高版本。
- 需要 Git 和具有 GitHub 仓库写权限的 `GITHUB_TOKEN` 或 `GH_TOKEN`。
- 首次安装时，将整个 `a-skill-github-project-release` 目录放入 skills 路径。

## 平台与限制

- Windows、macOS 与 Linux。
- 不支持在原生 GitHub Markdown 中使用 JavaScript。
- 此版本支持三语 README，但 Release 正文仍是单一语言。

## 验证结果

- 首次发布配置、附件清单、目录更新和 Draft Release 流程通过离线测试。
