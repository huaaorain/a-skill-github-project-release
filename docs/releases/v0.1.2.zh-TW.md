## 版本摘要

`0.1.2` 為 skill 產生的專案介紹頁面加入清晰的語意圖示系統。新版參考 `prompt-optimizer` 的圖示式功能展示，使用少量固定含義的圖示區分功能、安裝、安全、下載與已驗證優勢，同時保留既有功能表格和中文短標籤不換行處理。

## 主要更新

- README 撰寫規則新增語意圖示約定：`✨` 表示功能，`🚀` 表示安裝或發佈流程，`🛡️` 表示安全與隱私，`📦` 表示下載附件，`✅` 只用於有實作、測試或相容性證據支持的優勢。
- README 範本新增 `✅ Key advantages` 區域，並為主要章節加入固定含義的圖示。
- 简体中文、繁體中文和 English 專案首頁同步採用相同的圖示意義和章節結構。
- 為頂部導覽使用的圖示標題增加明確 HTML 錨點，避免標題前綴變更導致頁內連結失效。
- 繼續保留功能表格和短中文標籤的窄不換行空格處理，不改變之前的欄寬最佳化。

## 問題修正

- 避免圖示只停留在靈感說明中而沒有落實到實際範本和專案頁面。
- 避免把 `✅` 當作純裝飾，或給尚未驗證的功能製造「已確認」的視覺暗示。
- 避免圖示標題破壞「核心能力」、「安裝」和「所有版本」等頁內導覽。

## 相容性與升級

- 從 `0.1.1` 升級不需要遷移專案資料或修改既有發佈附件。
- release manager 命令、Release 清單格式與多語系設定均保持相容。
- 既有專案可以逐步採用新範本；已經產生的專案頁面無需強制重寫。

## 平台與限制

- Windows、macOS 與 Linux。
- GitHub.com 與 GitHub REST API。
- 不同作業系統和字型可能以略有差異的樣式顯示彩色 emoji；固定錨點不依賴 emoji 的顯示效果。

- skill 結構驗證通過。
