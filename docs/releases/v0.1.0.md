# GitHub Project Release 0.1.0

## Summary

`0.1.0` 是 GitHub Project Release skill 的首个公开发布版本，提供从项目检查、GitHub 建库、源码推送、Draft Release、附件上传到 README 与多语言版本目录维护的完整工作流。

## Highlights

- 首次公开发布默认使用 `0.1.0`，不再自动从 `1.0.0` 开始。
- 默认采用 `release-only`：源码进入 Git，可执行程序与分发文件只上传到 Release。
- 支持首次建库与已有仓库的新版本发布。
- 为每个附件生成用途、类型、大小和 SHA-256 清单。
- 根据上一版本标签和 commit 差异生成可审核的版本说明。
- 支持 Draft Release、附件续传和发布前一致性校验。
- 支持简体中文、繁体中文和英文 README，并同步更新版本目录。
- 提供功能截图规范、README 模板和发布说明契约。
- 可仅更新已有 Release 的说明，不修改标签、附件或校验文件。

## Fixes and improvements

- Draft Release 通过已认证的 Release 列表发现，避免按标签接口漏掉草稿。
- Draft 附件通过 Release Asset API 读取，避免临时 `untagged-*` 链接失效。
- 默认初始版本由发布配置约束，并包含离线回归测试。

## Compatibility and upgrade notes

- 运行环境需要 Python 3.10 或更高版本。
- 需要 Git 和具有 GitHub 仓库写权限的 `GITHUB_TOKEN` 或 `GH_TOKEN`。
- 首次安装时，将整个 `github-project-release` 目录放入 skills 路径。
- 不需要 GitHub CLI。

## Platforms

- Windows、macOS 与 Linux
- GitHub.com 与 GitHub REST API
