## 版本摘要

`0.1.1` 为 GitHub Release 正文加入折叠式多语言支持。默认只展开简体中文，用户可点击繁體中文或 English 展开对应说明；下载文件表只显示一次，不再重复三种语言。

## 主要更新

- 新增 `release_notes.locales` 配置，可为每个版本维护简体中文、繁体中文和英文说明源文件。
- 新增 `render-localized-notes` 命令，可生成 `accordion` 或 `anchors` 两种 Release 正文布局。
- `accordion` 模式默认只展开一种语言，其他语言以折叠标题呈现。
- 文件下载表统一放在语言内容之外，只显示一次。
- 附件说明支持按语言分别配置，并在统一表格中合并中文与英文用途。
- 预检会检查语言选择器、默认展开项、附件名和文件表完整性。

## 问题修复

- 补齐此前仅支持三语 README、但不支持三语 Release 正文的差距。
- 避免三种语言完整正文同时展开导致 Release 页面过长。
- 保留传统页内锚点模式，供需要一次查看全部语言的场景使用。

## 兼容性与升级

- 从 `0.1.0` 升级不需要迁移项目数据。
- 既有 README 多语言配置和发布附件保持不变。
- 为项目增加 `release_notes.locales` 后，使用新的本地化正文渲染命令。
- GitHub 原生 Markdown 不支持 JavaScript，因此折叠面板不是严格互斥标签页。

## 平台与限制

- Windows、macOS 与 Linux。
- GitHub.com 与 GitHub REST API。
- 真正的原地标签页切换仍需要独立的 GitHub Pages 页面。

## 验证结果

- 三语折叠正文、默认语言、统一文件表和本地化预检通过离线测试。
- 发布前确认 Release 标签、附件哈希和源文件提交一致。
