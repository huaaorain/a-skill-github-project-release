## Summary

`0.1.1` adds collapsible multilingual Release notes. Simplified Chinese is expanded by default, while Traditional Chinese and English can be opened from their summaries. The download table appears once instead of being duplicated for each language.

## Highlights

- Added `release_notes.locales` for per-version Simplified Chinese, Traditional Chinese, and English source files.
- Added `render-localized-notes` with `accordion` and `anchors` layouts.
- Accordion mode expands one language by default and keeps the other languages collapsed.
- The shared file table appears once after the language sections.
- Asset descriptions can be localized and combined into one Chinese/English table row.
- Preflight checks language selectors, the default-open block, asset names, and the shared file table.

## Fixes

- Closed the gap between localized README support and single-language Release bodies.
- Prevented three complete release descriptions from expanding and making the page excessively long.
- Preserved the anchor-based layout for users who prefer all languages expanded at once.

## Compatibility and upgrade

- Upgrading from `0.1.0` requires no project-data migration.
- Existing README locale settings and release assets remain unchanged.
- Add `release_notes.locales` to a project and use the new localized renderer.
- GitHub Markdown cannot execute JavaScript, so the collapsed panels are not strictly exclusive tabs.

## Platforms and limitations

- Windows, macOS, and Linux.
- GitHub.com and the GitHub REST API.
- True in-place tab switching still requires a separate GitHub Pages site.

## Verification

- Localized accordion rendering, default-language selection, the shared file table, and localized preflight passed offline tests.
- Release tags, asset hashes, and source commits are checked before publishing.
