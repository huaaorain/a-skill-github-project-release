## Summary

`0.1.0` is the first public release of A Skill: Github Project Release. It provides a complete workflow from project inspection and GitHub repository creation through source updates, Draft Releases, asset uploads, README generation, and multilingual download catalogs.

## Highlights

- New projects start at `0.1.0` by default.
- Uses a release-only policy: source stays in Git while executables and distributables are published as Release assets.
- Supports both first-time repositories and new versions in existing repositories.
- Produces purpose, type, size, and SHA-256 records for every asset.
- Supports Draft Releases, resumable uploads, and consistency checks before publishing.
- Maintains Simplified Chinese, Traditional Chinese, and English README files and release catalogs.

## Fixes

- Draft Releases are discovered through the authenticated release list.
- Draft assets are read through the Release Asset API instead of temporary download URLs.
- The default initial version is enforced by configuration and covered by an offline regression test.

## Compatibility and upgrade

- Requires Python 3.10 or newer.
- Requires Git and a `GITHUB_TOKEN` or `GH_TOKEN` with repository write access.
- Install the complete `a-skill-github-project-release` directory in the skills path.

## Platforms and limitations

- Windows, macOS, and Linux.
- Native GitHub Markdown cannot execute JavaScript.
- This version supports localized READMEs, but the Release body is still single-language.

## Verification

- Initial-release configuration, asset manifests, catalog updates, and the Draft Release flow passed offline tests.
