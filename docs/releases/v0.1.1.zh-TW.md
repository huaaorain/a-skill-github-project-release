## 版本摘要

`0.1.1` 為 GitHub Release 正文加入摺疊式多語系支援。預設只展開簡體中文，使用者可點擊繁體中文或 English 展開對應說明；下載檔案表只顯示一次，不再重複三種語言。

## 主要更新

- 新增 `release_notes.locales` 設定，可為每個版本維護簡體中文、繁體中文與英文說明來源檔案。
- 新增 `render-localized-notes` 命令，可產生 `accordion` 或 `anchors` 兩種 Release 正文版面。
- `accordion` 模式預設只展開一種語言，其他語言以摺疊標題呈現。
- 檔案下載表統一放在語言內容之外，只顯示一次。
- 附件說明支援依語言分別設定，並在統一表格中合併中文與英文用途。
- 預檢會檢查語言選擇器、預設展開項目、附件名稱與檔案表完整性。

## 問題修正

- 補齊此前僅支援三語 README、但不支援三語 Release 正文的差距。
- 避免三種語言完整正文同時展開導致 Release 頁面過長。
- 保留傳統頁內錨點模式，供需要一次查看全部語言的場景使用。

## 相容性與升級

- 從 `0.1.0` 升級不需要遷移專案資料。
- 既有 README 多語系設定和發佈附件保持不變。
- 為專案增加 `release_notes.locales` 後，使用新的本地化正文渲染命令。
- GitHub 原生 Markdown 不支援 JavaScript，因此摺疊面板不是嚴格互斥標籤頁。

## 平台與限制

- Windows、macOS 與 Linux。
- GitHub.com 與 GitHub REST API。
- 真正的原地標籤頁切換仍需要獨立的 GitHub Pages 頁面。

## 驗證結果

- 三語摺疊正文、預設語言、統一檔案表與本地化預檢通過離線測試。
- 發佈前確認 Release 標籤、附件雜湊與來源檔案提交一致。
