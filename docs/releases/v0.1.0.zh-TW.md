## 版本摘要

`0.1.0` 是 A Skill: Github Project Release 的首個公開發佈版本，提供從專案檢查、GitHub 建庫、原始碼推送、Draft Release、附件上傳到 README 與多語系版本目錄維護的完整工作流程。

## 主要更新

- 首次公開發佈預設使用 `0.1.0`。
- 預設採用 `release-only`：原始碼進入 Git，可執行檔與分發檔案只上傳到 Release。
- 支援首次建庫與既有倉庫的新版本發佈。
- 為每個附件產生用途、類型、大小與 SHA-256 清單。
- 支援 Draft Release、附件續傳與發佈前一致性檢查。
- 支援簡體中文、繁體中文與英文 README，並同步更新版本目錄。

## 問題修正

- Draft Release 透過已驗證的 Release 清單尋找。
- Draft 附件透過 Release Asset API 讀取，避免臨時連結失效。
- 預設初始版本由發佈設定約束，並包含離線回歸測試。

## 相容性與升級

- 執行環境需要 Python 3.10 或更新版本。
- 需要 Git 與具有 GitHub 倉庫寫入權限的 `GITHUB_TOKEN` 或 `GH_TOKEN`。
- 首次安裝時，將整個 `a-skill-github-project-release` 目錄放入 skills 路徑。

## 平台與限制

- Windows、macOS 與 Linux。
- 不支援在原生 GitHub Markdown 中使用 JavaScript。
- 此版本支援三語 README，但 Release 正文仍是單一語言。

## 驗證結果

- 首次發佈設定、附件清單、目錄更新與 Draft Release 流程通過離線測試。
