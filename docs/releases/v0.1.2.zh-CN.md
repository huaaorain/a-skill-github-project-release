## 版本摘要

`0.1.2` 为 skill 生成的项目介绍页面加入清晰的语义图标体系。新版参考 `prompt-optimizer` 的图标式功能展示，使用少量固定含义的图标区分功能、安装、安全、下载和已验证优势，同时保留现有功能表格与中文短标签不换行处理。

## 主要更新

- README 编写规则新增语义图标约定：`✨` 表示功能，`🚀` 表示安装或发布流程，`🛡️` 表示安全与隐私，`📦` 表示下载附件，`✅` 只用于有实现、测试或兼容性证据支持的优势。
- README 模板新增 `✅ Key advantages` 区域，并为主要章节添加固定含义的图标。
- 简体中文、繁體中文和 English 项目首页同步采用相同的图标语义和章节结构。
- 为顶部导航使用的图标标题增加显式 HTML 锚点，避免标题前缀变化导致页内链接失效。
- 继续保留功能表格和短中文标签的窄不换行空格处理，不改变之前的列宽优化。

## 问题修复

- 避免图标只停留在灵感说明中而没有落实到实际模板和项目页面。
- 避免把 `✅` 用作纯装饰，或给尚未验证的功能制造“已确认”的视觉暗示。
- 避免图标标题破坏“核心能力”“安装”和“所有版本”等页内导航。

## 兼容性与升级

- 从 `0.1.1` 升级不需要迁移项目数据或修改已有发布附件。
- release manager 命令、Release 清单格式和多语言配置均保持兼容。
- 现有项目可以逐步采用新模板；已经生成的项目页面无需强制重写。

## 平台与限制

- Windows、macOS 与 Linux。
- GitHub.com 与 GitHub REST API。
- 不同操作系统和字体可能以略有差异的样式显示彩色 emoji；固定锚点不依赖 emoji 的显示效果。

## 验证结果

- release manager 的 9 项离线测试全部通过。
- skill 结构校验通过。
- 三语 README 的 4 个页内导航链接均能找到对应显式锚点。
