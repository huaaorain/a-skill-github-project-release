# GitHub Project Release 1.0.2

## Summary

`1.0.2` 是 GitHub Project Release skill 的首个公开发布版本，提供从项目检查、GitHub 建库、源码推送、Draft Release、附件上传到 README 与多语言版本目录维护的完整工作流。

## Highlights

- 默认采用 `release-only`：源码进入 Git，可执行程序与分发文件只上传到 Release。
- 支持首次建库与已有仓库的新版本发布。
- 为每个附件生成用途、类型、大小和 SHA-256 清单。
- 根据上一版本标签和 commit 差异生成可审核的版本说明。
- 支持 Draft Release、附件续传和发布前一致性校验。
- 支持多语言 README，并同步更新每种语言的版本目录。
- 提供功能截图规范、README 模板和发布说明契约。
- 可仅更新已有 Release 的说明，不修改标签、附件或校验文件。

## Fixes and improvements

- 修复无法通过标签入口发现 Draft Release 的问题。
- 改为在已认证的 Release 列表中匹配 Draft 标签。
- 修复 Draft 临时下载 URL 不可用的问题。
- 改为通过 Release Asset API 读取 Draft 元数据。
- 增加 Draft 发现逻辑的离线回归测试。

## Compatibility and upgrade notes

- 运行环境需要 Python 3.10 或更高版本。
- 需要 Git 和具有 GitHub 仓库写权限的 `GITHUB_TOKEN` 或 `GH_TOKEN`。
- 首次安装时，将整个 `github-project-release` 目录放入 skills 路径。
- 不需要 GitHub CLI。

## Platforms

- Windows、macOS 与 Linux
- GitHub.com 与 GitHub REST API
